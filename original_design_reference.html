How it works

1. Import

Type, paste, speak or upload a .txt, .csv or Excel file.

2. Analyse

Keyword rules tag each comment with themes and a sentiment, handling words like “not good”.

3. Report

Charts, a word cloud, theme summaries and an improvement plan appear instantly.

About the project

Problem

Feedback arrives as many free-text comments. Reading them one by one is slow, and recurring issues get missed.

Solution

A browser app that groups comments into themes, measures sentiment and turns the result into actions.

Features

Eight themes, sentiment charts, word cloud, filters, history, Excel and PDF export, voice input, teacher and student views.

Future scope

Python backend with SQLite, TF-IDF clustering, multilingual detection, and report writing with an LLM API such as Claude.

Technology used

HTML, CSS, JavaScript, Tailwind CSS, Chart.js, SheetJS, Web Speech API, localStorage.
